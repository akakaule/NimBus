# Implementation plan

1. Add failing Node tests for report status aggregation, retry handling, incomplete
   runs, global errors and safe HTML output.
2. Implement a standalone report generator driven by the Playwright catalog and
   results, including run provenance and searchable scenario results.
3. Configure CI reporters and npm scripts; add the manual/nightly Aspire workflow,
   artifact generation, bounded diagnostic collection and unconditional cleanup.
4. Document run instructions and distinguish historical coverage from current runs.
5. Verify report tests, TypeScript, actual Playwright catalog/report compatibility,
   HTML rendering and workflow lint. A hosted execution requires publishing the
   workflow; report that separately from local validation.
